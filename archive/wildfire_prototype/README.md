Wildfire real-data prototype

This directory contains an experimental extension toward real wildfire,
weather, population and geospatial datasets.

It is not part of the reproducible C0 pipeline submitted to the Tesseract
Hackathon 2026.

The current prototype depends on the unavailable wildfire_shared package.
It is archived as future work.

The submitted C0 pipeline uses documented synthetic data so that the ground
truth is known and the end-to-end gradients can be validated numerically.
